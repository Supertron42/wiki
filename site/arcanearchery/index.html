Arcane Archery

Select a spell and carry it with your arrows. Each fired arrow remembers its selected spell, so changing the selection affects later shots rather than arrows already in flight.

Source preview: gameplay and visual compatibility remain limited.

Get started

  1. Choose the plugin download for your exact Skyrim version and store edition. Use the matching SKSE and Address Library required by that download.
  2. Install the complete package with your mod manager, including its Data assets. Back up personal settings before replacing an older mod folder.
  3. Start Skyrim through SKSE. For these settings, restart Skyrim after saving changes unless the guide describes a separate reload control.

Settings

SettingWhat it changes
Bind a spellNumpad 1 selects the spell equipped in either hand. Numpad 2 clears it by default; an existing clear-key choice is preserved.
MagickaThe cost is charged when a spell arrow successfully launches, including misses. Without enough magicka, the arrow fires normally.
Visuals and soundChoose drawn-arrow, flight and target artwork and sounds in ArcaneArchery.json or the optional menu. A spell needs suitable artwork or sounds to supply them.
Advanced overridesPer-spell artwork overrides and NPC entries use plugin filename plus local form ID. Leave these empty unless you have the correct records from xEdit.

Limits and troubleshooting

  • This source preview still needs rebuilt and in-game visual/audio checks. Earlier testing reported missing magic effects on drawn or flying arrows; the latest correction is not proof that every spell now looks right.
  • Ordinary single-cast spells and lesser powers are candidates. Concentration spells, shouts and location-targeted spells such as runes are rejected.
  • The current source deliberately rejects Skyrim 1.7.x. Do not use a general combined-build label as a compatibility promise.
  • Draw previews are for a player bow with a loaded arrow model. NPC/crossbow draw previews and controller/VR key binding need separate work.
  • The current drawn-arrow source trial centers the selected spell's hand artwork near the arrowhead and preserves its original size. Placement is calibrated for vanilla arrows. Custom meshes and animated effects need game testing. Explicit artwork overrides keep their existing behavior.
  • In-flight bindings clear when a save loads. The selected spell is retained in the SKSE co-save.
