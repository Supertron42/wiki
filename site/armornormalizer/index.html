Armor Normalizer

Adjust recognized modded armor toward the game’s material-tier standards for protection, weight and value. Separate options cover crafting recipes, crafting exclusions and adding armor to world loot.

Get started

  1. Choose the plugin download for your exact Skyrim version and store edition. Use the matching SKSE and Address Library required by that download.
  2. Install the complete package with your mod manager, including its Data assets. Back up personal settings before replacing an older mod folder.
  3. Start Skyrim through SKSE. For these settings, restart Skyrim after saving changes unless the guide describes a separate reload control.

Settings

This project uses INI settings and MCM Helper, rather than PUISM JSON settings. Use Data/MCM/Settings/ArmorNormalizer.ini when supplied by MCM; the older fallback is Data/SKSE/Plugins/ArmorNormalizer.ini. Restart after changes.

SettingWhat it changes
FeaturesStat normalization, crafting normalization and distribution start on. The crafting blacklist starts off.
StatsThe default armor-rating multiplier is 1.1. Value and weight multipliers start at 1.0.
DistributionThe default chance is 25%, with merchant and chest distribution enabled.
Crafting blacklistChoose detected plugins whose recipes should be blocked, then restart.

Limits and troubleshooting

  • The source skips base-game armor, clothing, non-playable armor and material/slot combinations it cannot classify.
  • Material detection uses available names, keywords and recipes; unusual modded equipment may need review.
  • This changes the result used by the running game. Keep other armor balancing and distribution mods in mind when testing.
  • An MCM source script is present; menu use requires a complete matching packaged MCM setup. The source tree alone is not a player download.
