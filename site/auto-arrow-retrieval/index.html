Auto Arrow Retrieval

The current prototype gives the player a 50% chance to receive one unit of their currently equipped ammunition after a kill credited to the player.

Experimental prototype.

Get started

This is an experimental source project. Use a separately built, tested plugin on a test setup; the template README does not describe a finished download. There is no configuration menu in the current source.

Settings

SettingWhat it changes
Recovery chanceFixed at 50% in the current source.
Returned ammoUses the ammunition equipped when the death event is handled.
FeedbackA notification says Recovered an arrow when the grant occurs.

Limits and troubleshooting

  • It does not track the ammunition that caused the kill or recover individual fired projectiles.
  • A player kill is the trigger; the source does not require that the killing blow was an arrow.
  • Changing equipment before the event can affect which ammo is returned. Runtime and gameplay behavior still need validation.
