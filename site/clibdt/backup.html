Backup and restore

Keep recoverable project snapshots and file-folder backups.

Choose the backup

Developer-folder backups can include several folders with exclusions. Unchanged content is stored once in the shared files folder used by the backup records. Keep those files and records together.

Project snapshots

A project snapshot retains source and exact selections while excluding build caches and shared source trees. Keep the shared Libraries store too when you need offline recovery.

Restore into a new folder

Restore creates a new folder with numbered source folders. The record keeps the original paths for reference; review the recovered contents before replacing any working copy.

Check your recovery

Keep a separate copy on another device before important releases or workspace cleanup. Open a restored snapshot and verify the source and dependency inputs you need.
