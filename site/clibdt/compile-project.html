Compile and test copies

Build selected projects and control where complete test mods are copied.

Choose the build

Select project, runtime, build configuration and clean option. The combined desktop target enables the supported desktop families in one DLL; VR is separate. Individual profiles remain available.

Multi compile

Select the projects and versions for a batch. Copying test mods is explicit and uses one selected game version so competing builds do not replace one another.

Copy or keep output only

A normal single-project compile can install the complete named mod into the primary compiled-mod folder and additional copy folders. Compile without copying to folders avoids those installations but still retains verified artifacts and receipts.

Saved build checks

The toolkit checks source, dependencies and produced DLL identity. Changed build inputs invalidate an older receipt. Compiler success and correct metadata still need game testing.

If it fails

Read the first useful compiler error. Check the chosen library and tool versions before changing code. Never upgrade a library merely to hide an unresolved source error.
