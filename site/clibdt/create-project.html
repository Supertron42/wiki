Create or import a project

Start a plugin with its intended source libraries and game target.

Choose project details

Enter the project name, author, version and target, then review the selected CommonLib and optional headers. Creation uses a bundled starter; it does not download an unrelated sample project.

Create

Check the destination before confirming. Open the new source, make the intended change and compile for a runtime supported by both its code and library.

Import legacy source

Import legacy project makes a separate imported copy. It preserves exact dependency snapshots and original source compatibility choices. It cannot repair an existing C++ error or infer a custom CMake adapter.

Keep inputs together

Keep authored source, resources and build definitions with the project. Installed files, temporary output and personal settings remain separate.
