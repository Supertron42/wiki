First project

Set up the toolkit and build a small test plugin.

Set up

  1. Choose a development folder in Set Paths.
  2. Install Git, Xmake, the Windows C++ tools and a CommonLib source in Tools and Libraries. Linux cross-compilation has separate prerequisites.
  3. Create a project and select the library/runtime it should use.

Build and test

Compile the chosen runtime, inspect the checked DLL and complete mod folder, then test through the matching SKSE/game setup. A successful compiler run does not establish gameplay support.

Keep projects stable

New library installations do not update existing projects. Review an explicit update or import before changing library selections. Use Release Project only with current checked builds.
