Development tools and libraries

Install the tools that turn source code into a Skyrim plugin.

Check what is installed

Tools and Libraries shows tool/library status. Detect an existing installation or explicitly install a managed one. Selecting a screen does not silently install tools.

Windows compiler

The Windows workflow uses Microsoft C++ Build Tools, including its compiler, Windows SDK and C/C++ headers. Finish the official installer before compiling.

Xmake and Git

Xmake configures and builds supported projects; Git retrieves source histories. ClibDT checks supported tool versions and explains when an installed version is too old.

Project libraries

Choose CommonLib for the intended game/plugin. CLibUtil and xbyak are optional shared headers for projects that use them. Existing project pins stay unchanged until an explicit update review.

GitHub Desktop

GitHub Desktop has guided setup. Source repositories and documentation are separate; publishing source is your own reviewed action.
