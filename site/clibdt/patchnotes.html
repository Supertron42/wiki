Version 5.3 (unreleased)

Prepared for testing. Game compatibility is not yet certified.

  • Package the same source version again with the previous ZIP backed up automatically.
  • Make Source ZIP includes only the selected mod's src folder.
  • Package ClibDT's own source without rebuilding its EXE.
  • Source packaging stops if required files are missing or change during packaging.
  • Project dots update automatically when relevant files or finished builds change.
  • Project dots recheck only changed files while monitoring is active, so small edits show their result much sooner.
  • Returning to Compile Project keeps the cached colors for the selected game version and configuration.
  • Green means the saved build matches, red means compilation is needed, and grey means a result is unknown or the check is unavailable.
  • Unavailable checks retry automatically, and an edit updates only the affected project.
  • Multi compile shows the same icons without changing your checked projects.
  • Checks run in the background, and Check changes forces a fresh read when you want to verify every project.
  • Dot caches speed up the display while packaging and publishing still perform their own full validation.
  • Skyrim 1.6.x has its own choice in Compile Project and Release Project, with separate output folders, release names and portable setup instructions.
  • Packaging and Nexus publishing now have their own Release Project tool under Projects. Saved Mod IDs are retained, and builds are checked before packaging or publishing.
  • Active operations stay open when changing tools or closing the main window.
  • Current Skyrim support. Projects can use CommonLibSSE-NG 7.5.1 to prepare builds for Skyrim 1.7.104.
  • Library updates. Update CommonLib prepares the selected project and keeps its previous library and dependency settings in a backup.
  • Correct build selection. Switching between SE, AE and VR clears the other choices and keeps each build separate.
  • Reliable versions. The project version stays consistent between ClibDT, the build settings and the finished mod.
  • Checked packages. Release packages require a matching current build and preserve previous packages.
  • Matching SKSE. The installer points Steam 1.7.104 users to SKSE 2.3.1 and keeps older game choices separate.
  • Toolkit releases. ClibDT can build and package its own current executable together with complete source files.
