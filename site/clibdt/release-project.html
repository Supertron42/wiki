Prepare a release

Package current verified output and review publication separately.

Review package contents

Choose the checked project/runtime/configuration. Review the DLL, Data assets, required notices and any selected saved FOMOD recipe. Release stops if source/dependency/output hashes no longer match.

Include source

Source ZIP can contain src alone or source plus build files. Select the complete build inputs when sharing a rebuildable project. Dependency licenses can require additional notices/source; a license menu choice does not replace them.

Publish only after review

Preparing an archive does not upload it. Nexus publication has its own review and explicit confirmation. An interrupted uncertain upload stops so you can check the website before retrying.

Existing versions

Binary release archives are not silently overwritten. A same-version source replacement is prepared and verified, with the previous source archive backed up first. Test the final installer in the intended mod manager and game.
