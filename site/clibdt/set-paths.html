Paths and existing projects

Choose the folders the toolkit will use before creating or connecting projects.

Development folder

Review the Projects, Tools, Libraries, game and compiled-mod destinations, then Save. Unsaved edits are separate from the paths active tools use.

Game and output folders

Use the real intended game folder and the compiled-mod destination. SKSE archive storage is separate from the actual game installation. Additional copy folders are separate from the primary compiled-mod folder.

Connect an existing workspace

Choose Review import. Use existing folders reconnects eligible projects after review; Make a separate copy keeps the old setup untouched. Review whether exact local library copies will be kept or freed. Unsupported/custom layouts and unresolvable source conflicts stop for review.

Saved paths

Windows saves the relevant user path variables without replacing the global PATH. Linux scopes paths to builds and offers an environment file. Restart another tool if it needs newly saved user variables.
