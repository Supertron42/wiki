Toolkit settings

Choose presentation and optional account/developer controls.

Appearance

Choose the theme and accent controls provided by the current application. Presentation settings do not alter project source, dependency versions or game files.

Nexus credentials

Connecting a Nexus key is optional for local development. Saved keys use the operating system credential store rather than the settings JSON. Direct Nexus download privileges still depend on the account.

Developer tools

Enable Show developer tools to select the toolkit’s SRC folder and use its own source build/package workflows. Compiler setup, building, packaging and publishing are separate actions. Close the running toolkit before applying an external replacement build.

Review before reset

Back up useful preferences before resetting them. A reset is not a project migration or a dependency update.
