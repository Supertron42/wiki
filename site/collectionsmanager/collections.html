Saved collections

Load and maintain saved collection definitions.

Load a saved collection

Choose the saved collection or import its local ZIP, then review it in Install. Keep an imported ZIP available while editing bundled contents. A saved definition is not a copy of all downloaded mods unless those files were explicitly bundled.

Review versions and sources

Loading another revision of the same collection opens a comparison of added, removed, changed and unchanged items. Inspect optional choices, instructions, programs and settings where available. Load revision for review loads the definition and checks existing files; it does not install anything. Cancel keeps the previous collection and installation context.

Exact-source optional exclusions can carry forward. Removed mods remain installed, and MO2 profiles continue to share mod folders. Review replacements deliberately; a changed definition does not isolate or rebuild the installed setup.

Review source and version changes before downloading or reinstalling. A new name or matching folder does not prove that an existing installation matches the requested file.

What is saved

Definitions can retain mod sources, order, enabled state, installer choices, instructions, bundled content, INI edits and program recipes. Account keys and personal installed paths are not portable library fields.

Remove deliberately

Read the action’s review before deleting a saved definition or uninstalling installed content. Those are separate operations. A saved collection does not provide independent revision isolation for every installation.

Keep a recoverable copy

Keep the exported ZIP and any needed source archives. Export publishes a complete ZIP after success; cancellation or failure preserves a previous export. Test an import in a separate MO2 profile before sharing it.
