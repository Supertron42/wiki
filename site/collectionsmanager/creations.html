Create a portable collection

Turn a reviewed MO2 setup into a portable collection ZIP.

Start from the active profile

Choose Load MO2 Mods and confirm whether enabled, disabled or both kinds of mods belong in the collection. Review recognized sources, order, activation and saved installer choices. This review does not change MO2’s installed mods.

Customize or combine collections

In Install, use Save as MO2 Collection while installation is idle. Review what to keep, give the copy a name and version, then continue editing in Create. Failed or unfinished items remain for review.

Use Load from > Merge two collections for local MO2 Collection ZIP or JSON sources for the same game. Review differing versions, installer choices, settings and programs; arrange the final mod order. The result is a separate editable collection with original authors and source revisions credited.

Save the Create profile to continue later. Exporting a ZIP does not begin installation.

Review each source

Confirm pinned Nexus files and external links. Choose explicitly which custom files belong in a bundle. Adding a source reference does not grant redistribution permission for its files.

Files and INI edits

Mod settings can compare chosen text/INI/JSON configuration with a known clean baseline and save selected line differences. Missing or ambiguous baselines need an explicit clean file. Recipients review their actual changes and conflicts before applying them.

Include generated Overwrite files

  1. Open Files & INI edits > Bundle files and choose Choose Overwrite files.
  2. Expand folders and check the files or folders to include. New files start unchecked; review the selected file count and size.
  3. Choose a distinct Included mod name, then Apply to commit the selection.

The ZIP embeds selected files with their paths preserved. Recipients install them as the named included MO2 mod; their Overwrite folder stays unchanged. Source files stay in place. Cancel preserves your existing draft, and files changed or removed after selection need review before export.

Saved author profiles retain local selections. Imported ZIPs can be exported again from their embedded files without the original Overwrite folder.

Include program recipes

Add configured programs copies portable recipes from Programs. Review destination, archive folder, included files, executable paths and launch mode. Actual installed paths, cached downloads and credentials are not published. Avoid including the same tool both as a pinned mod and as a program for the same destination.

Review and export

Use Review & export, resolve the item/source/setup problems and export the ZIP. A success summary means those reviewed items have no reported issues; it does not prove that every remote archive is available or that installation will succeed.

Test before sharing

Import the ZIP in a separate test profile and inspect installers, settings changes, launchers and gameplay. Keep the source ZIP available for bundled files. Automatic requirements-chain management and isolated collection revisions are not finished features.
