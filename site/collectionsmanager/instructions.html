First collection

Connect your account, review a collection and work through its installation in MO2.

Connect Nexus

Use the account controls to connect your Nexus account. Keep API keys private. Premium supports automatic Nexus downloads; free accounts follow the website’s manual steps. Account previews and appearance settings do not change your Nexus permissions.

Load and review

  1. Choose a Nexus collection or import a local collection ZIP.
  2. Read the author’s instructions and choose optional items. Review external sources, installer choices, bundled files, INI changes and programs.
  3. Use Start when the review is ready. Downloads may overlap, but MO2 installers run one at a time in order.

While installation runs

The Install sidebar contains Start, Stop and Options. Progress shows completed installation totals and current activity. Stop cancels pending work; wait for the current installer or worker to finish before Resume. An operation that completed just before Stop remains completed.

Resolve unfinished items

Use Needs attention or Fix Failed to see the actual reason. Choose Fix / Install for a saved supported item, Locate archive if its download moved, or Open source to obtain it. Successful completion clears the matching reminder; skipping does not count as installed.

Check your result

Check MO2’s installed mods, activation and intended profile order. Resolve outstanding manual instructions, launchers and installer choices before starting the game. A finished queue is not an in-game compatibility test.
