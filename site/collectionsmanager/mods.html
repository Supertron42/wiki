Install list and downloads

Review the collection’s mods and choose what will be installed.

Read the install list

Load a collection first. Inspect required, optional, external and bundled items, their source, available archive and current status. Right-click choices are available before starting the queue.

Choose download flow

Premium uses the supported automatic Nexus path. Free accounts use the selected file’s website steps. You can attach a matching local download; do not substitute an unrelated version just because its filename looks similar.

Start and stop

Start runs the reviewed queue. Stop cancels pending work and requests worker cancellation. Wait for the active MO2 installer or native operation before resuming. A skipped entry stays unfinished.

Needs attention

Read the reason before retrying. Missing downloads, a manual installer decision, an unsupported archive or an incomplete program recipe need different actions. Fix Failed keeps saved repair items available even when their original collection is not loaded, where the source is complete enough to do so.

Bundled contents

Review files, INI edits and binary patches in the collection bundle before accepting. Missing targets or unsupported layouts can prevent an intended change. A normal failed write attempts recovery; independent backups still matter.
