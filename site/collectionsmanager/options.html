Settings and account choices

Choose install preferences and interface behavior for this MO2 instance.

Install preferences

Review automatic installation/activation, download concurrency and manual-installer behavior for the current task. Reducing the download limit affects new transfers, not those already running.

Nexus account

Connect the intended account and refresh its status when needed. Premium permissions come from Nexus; selecting an appearance or developer account preview does not grant them. Keep keys out of screenshots and shared collection files.

Window and appearance

Choose fixed or remembered window dimensions, reset them when needed, and set the next-open always-on-top choice. Custom icon families can be applied to the open window. Colors and fonts follow MO2’s theme.

Advanced choices

Change archive-tool or diagnostic settings only for a known need. Detailed logs are useful for a reproducible problem; review a log before sharing it, especially older logs created before current redaction behavior.

Save and verify

Confirm that the intended settings saved. Program setup, library import and collection export have separate review/save actions; changing a global preference does not install a tool or finish an unresolved installer.
