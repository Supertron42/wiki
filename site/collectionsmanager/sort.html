Use the review

  1. Load the intended collection/profile and inspect the current mod order.
  2. Compare conflicting files and the proposed ordering choices. Add or revise explicit rules where needed.
  3. Resolve conflicting/cyclic rules before applying the reviewed result.
  4. Check MO2’s resulting left-pane order and test the affected mods.

Rules and conflicts

Rules explain which mod should win a file conflict or appear relative to another. Review the affected mods rather than sorting only by names. Incompatible rules can form a cycle and need a deliberate choice.

Mod order is not plugin order

This workflow concerns mod-file priority in MO2. It is not a substitute for checking the separate ESP/ESM/ESL load order, required masters or a plugin-ordering tool.

Keep a comparison

Use a named profile snapshot before a large reorder. Review which profile/order/settings the restore action will affect. A snapshot is a recovery aid, not a full independent copy of every installed mod or an isolated collection revision.
