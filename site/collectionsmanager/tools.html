Maintenance and repair tools

Inspect the result before applying cleanup or game-folder changes.

Choose a focused tool

Use maintenance, duplicate checks, master checks or root/game-folder setup for the problem you are investigating. Read the preview and affected paths before accepting an action.

Metadata and duplicates

Rebuilding an index or repairing markers helps CM recognize its state. Duplicate detection needs review: two archives or folders can serve different versions or purposes. Do not remove a candidate solely because it has a similar name.

Missing masters

Inspect the plugin and the named missing requirement. Install or enable the correct master when appropriate. A metadata warning alone cannot choose a compatible version for your entire mod list.

Game-folder content

Review the destination beside the game executable and the archive layout. Programs such as SKSE use narrowly checked source/runtime/member rules. Nothing is automatically run to test a tool.

Recovery limits

CM stages supported changes and attempts to restore its replaced files after an ordinary failure or cancellation. It does not make a multi-folder operation immune to power loss or replace independent backups.

Preview a record merge

Tools > Conflict resolver currently supports Skyrim Special Edition plugin files. Select container, leveled-list or NPC categories, then Scan and preview. Read Changes and Skipped before saving a new ESP.

Supported rules compare container inventory, leveled-list entries and selected NPC inventory, spells, perks, factions and keywords. They preserve unrelated parts of the winning record. Scripts, packages, face appearance and FaceGen assets are outside these supported merges.

Include empty nested lists is optional and on by default. It includes qualified unchanged empty child overrides reachable from an exported leveled list, including through unchanged nonempty children. Unrelated empty lists are omitted. Turn it off to leave unchanged children in their original plugins; lists changed to empty by the merge still export.

Invalid intermediate records stop that branch and appear in Skipped. This option controls patch contents; it does not refill lists or capture changes made by a running plugin.

Save ESP creates a new output and does not install, enable or reorder it. Eligible existing-record overrides use an ESL-flagged ESP when the detected Skyrim SE runtime supports light plugins; older or unknown runtimes retain a full ESP. CM does not compact or renumber FormIDs.

Changing source files, load order, categories or the empty-list option requires a new preview. Disable an earlier CM patch before rescanning. Review the saved patch in xEdit before installing it through MO2 and testing the setup in game.
