Dynamic Location Discovery

Choose whether Skyrim plays the discovery jingle, shows the word Discovered, or displays location text. An experimental option can announce a known place when you leave and return.

Unreleased alpha; return announcements are experimental.

Get started

  1. Choose the plugin download for your exact Skyrim version and store edition. Use the matching SKSE and Address Library required by that download.
  2. Install the complete package with your mod manager, including its Data assets. Back up personal settings before replacing an older mod folder.
  3. Start Skyrim through SKSE. For these settings, restart Skyrim after saving changes unless the guide describes a separate reload control.

Settings

Edit Data/SKSE/Plugins/DynamicLocationDiscovery.json or the optional Prisma UI menu. Restart after changing settings.

SettingWhat it changes
Mute discovery soundOn by default.
Hide DiscoveredOn by default.
Show location names againExperimental and off by default. Turn it on to test return announcements.
Hide all location textOff by default. Hides the location announcements and their sound while leaving unrelated messages available.
Skip messages during combatOptional and off by default.
Repeat delay30 seconds by default; valid choices are 1 to 300 seconds. You must leave and return.

Limits and troubleshooting

  • An unreleased alpha, not a finished player download. HUD replacements, VR and actual location transitions still need testing.
  • Announcements depend on the game’s location boundaries and linked map markers. Moving within one location may not produce another message.
  • Disable the older Location Discovery plugin and other location-popup replacements while testing this one.
