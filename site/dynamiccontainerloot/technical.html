How container choices work

Understand the result before protecting a container or exporting a patch.

Starting result

The last loaded container version is the starting point. Earlier eligible versions contribute supported changes relative to the original. Skipping a contributor does not remove that starting result.

Counts and ownership

Comparisons retain source counts and supported ownership information. Repeated slots are not interchangeable with one total count; a direct amount choice applies to its supported source slot.

Optional patch output

ESP output is off by default. The writer checks supported records, references and patch ownership before replacing its own output. Unsupported fields or layouts can block output while the report still shows a calculated comparison.

Choose exclusions deliberately

Use record/item protection for a compatibility patch whose exact result must win. A skipped or failed comparison is not an empty container, and missing information is not guessed.
