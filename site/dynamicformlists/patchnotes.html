Current source notes

These are the current source notes. A source change needs a matching tested download before it is available to players. Use the overview for current setup and limits.

#NEW
- Review personal rules and installed compatibility packs in the Rules tab.
- Create mod groups and choose the game and DLC starting point by right-clicking plugins.
- See which rules affect a result and why that result was chosen.
- Browse changed form lists under their plugins and compare each mod beside the final result.
- Right-click a cell or drag it into the result to choose which changes to keep, then save and restart Skyrim.
- Right-click a plugin to skip its restored changes or leave its records as the last mod left them.
- Generate an optional ESP from your resolved lists using the JSON settings or PUISM.

- Tell Dynamic Form Lists to leave specific lists, entries or changes alone.
- Export your compatibility rules as a ZIP for others to install with their mod manager.
- Compatibility packs ignore missing mods, so one pack can work across different mod lists.

- Copy list details or individual changes directly from reports.

- Choose your Skyrim version, including VR, from one download.
- Keep your settings or install the optional default settings file.

Readable change reports

Reports now match the dark change sheet, with colored additions and removals, sortable columns, search, expandable details, and Mod changes selected by default.

Use Reason → Mod changes for the default view. Search by name, mod or record number, expand rows for exact values, and use Skipped to see exclusions or unapplied proposals. Missing names, sources and counts are not guessed. Rebuild the DLL and run Skyrim to generate the new report; the existing report paths and optional menu remain unchanged.

Version 0.1.0 release candidate

Unreleased source update; new builds, xEdit checks, and game testing are still required.

  • Optional shared menu. Edit settings through the shared menu or directly in the settings file, with no menu mod required.
  • Existing preferences preserved. Previous INI settings are imported once and the original file is kept.
  • Safer settings. Unreadable or unsupported settings stop restoration instead of silently changing lists with default preferences.
  • Searchable reports. Open a dated report in a browser or through the optional menu, even with detailed logging disabled.
  • Predictable list order. Existing entries keep their order and restored entries follow plugin order and their original order within each plugin.
  • Ordered-list protection. Lists with names ending in OrderedList are left unchanged by default.
  • Duplicate handling. Existing duplicate slots are preserved unless their entry is removed, and restoration does not introduce additional duplicates.
  • Safer plugin reading. Incomplete records, invalid references, deleted lists, and excessive data sizes are rejected before changing an affected list.
  • Script protection. Lists already changed by scripts or another runtime mod are left unchanged when that change can be detected.
  • Complete list replacement. The replacement list is prepared before changing the game data.
  • Matching xEdit rules. The optional companion script uses the same membership and ordering rules while preserving the final list name.
  • Safer selected-plugin patches. Selecting contributors in xEdit keeps the final loaded plugin as the starting list.
  • Updated build setup. CommonLibSSE-NG 7.5.1, consistent version information, and the corrected startup declaration prepare the project for new builds.
  • Optional ESP. Normal use requires no ESP, and the companion script still opens in report-only mode by default.

Version history and release notes for Dynamic Form Lists.

Newest releases appear at the top. Check back after updates to see what's changed.

Version 1.0.0 - Initial Release

Features

  • NEW Restores missing form list entries. When multiple mods edit the same form list, entries added by overridden mods are automatically restored at startup.
  • NEW Respects intentional removals. If a mod specifically removed an entry from a form list, it stays removed.
  • NEW xEdit companion script. Added ST - Dynamic Form Lists.pas for SSEEdit. Info Mode checks for broken references, null FormIDs, duplicates, and empty lists. Patch Mode creates a merged ESP.
  • NEW Skip specific mods via INI. Add plugin filenames to the skipMods setting to exclude them from processing.
  • NEW Skip specific form lists via INI. Add EditorIDs to the skipFormLists setting to leave certain lists untouched.
  • NEW Detailed optional logging. Turn on enablelogs to see exactly which entries were restored for each form list.
  • NEW SE, AE, and VR support. Single plugin binary covers all Skyrim editions via CommonLibSSE-NG.
