List modes and large results

Choose the behavior appropriate for your list setup.

Classic and newer modes

Classic is the current default and does not run newer script hooks or generate an ESP. Switching useClassicMerging off selects the newer path after restart. An enabled generated ESP bypasses runtime restoration in either mode.

Large lists

Split large lists is on by default. Above the supported entry limit, a result can use linked sublists. Turning splitting off skips that oversized conflict result rather than silently dropping entries.

Protected entries and cycles

Safety cleanup, protected entries and existing list cycles can interact. The mod logs cases it keeps or cannot resolve. Review the affected sources before removing protection.

Current settings format

Only version-2 JSON is accepted. INI and older JSON are not imported; keep a backup and install the current preset rather than editing only the version number.
