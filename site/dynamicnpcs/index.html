Dynamic NPCs

Restore NPC inventories, spells, perks, outfits and other supported changes lost when several mods edit the same character. You can choose appearance priority separately from the other restoration controls.

Get started

  1. Choose the plugin download for your exact Skyrim version and store edition. Use the matching SKSE and Address Library required by that download.
  2. Install the complete package with your mod manager, including its Data assets. Back up personal settings before replacing an older mod folder.
  3. Start Skyrim through SKSE. For these settings, restart Skyrim after saving changes unless the guide describes a separate reload control.

The gameplay plugin works on its own. You can edit its settings file with a text editor, or install Prisma UI Settings Menu and its requirements for an optional in-game editor. Press F10, choose the mod, save, and restart Skyrim. The menu definition shipped with a mod is separate from your personal settings file.

Settings

Edit Data/SKSE/Plugins/DynamicNPCs.json. Supported legacy settings are imported only while JSON is missing.

SettingWhat it changes
GeneralChoose which supported NPC data to restore, including inventory, spells, perks, outfits, behavior, factions and related fields.
FaceGenChoose appearance priority. The bottom matching entry wins. Install the face meshes and textures belonging to your chosen appearance mod.
CompatibilityCompare supported inventory, spell, perk, faction, package, keyword and outfit entries. Protected records and inherited fields keep their special handling.
Reports and logsHTML reports start on. Detailed logs start off. No exclusions or preferred appearance winners are selected for you.

Read the result

Open the mod’s HTML report in your SKSE log folder, or use View Report in the optional settings menu. Search for an item, record or source mod, expand a result, and use Copy record or Copy change to share the relevant details. Reports describe the recorded startup result; they do not change your settings or prove that a generated patch was saved.

Compatibility and Rules

Use Compatibility to compare the versions supplied by different mods. Right-click a plugin, record or supported result cell to see its choices. Save changes keeps your personal rules; Undo and Discard work on the unsaved draft. Restart Skyrim to apply saved rules. Rules lists personal choices and installed compatibility packs separately; installed packs are read-only, and exports contain saved personal choices only.

Skipping a mod’s contributions is different from protecting a record: the last loaded version still supplies the starting result. Protect a record when you want its existing result left alone. Missing optional mods do not make a whole compatibility pack mandatory. The settings menu remains optional, including when using compatibility packs.

Limits and troubleshooting

  • Appearance selection cannot supply missing face meshes or textures, and it is not a universal dark-face repair.
  • The comparison editor is limited to supported fields. It is not an unrestricted NPC editor for appearance, scripts or character structure.
  • The xEdit companion remains a separate reviewed patch workflow. A runtime report is not an automatically created NPC ESP.
  • Use a separately checked VR package when one is provided; a desktop package alone does not establish VR support.
