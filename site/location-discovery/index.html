Location Discovery

This older prototype changes two discovery presentation settings: it can mute the discovery sound and remove the word Discovered from location announcements.

Legacy prototype.

Get started

Treat this as a legacy source prototype. For the newer configurable work, see Dynamic Location Discovery. Do not enable both together.

Settings

The source reads Data/SKSE/Plugins/LocationDiscovery.ini. Under Settings, bMuteVanillaMusic and bRemoveDiscoveredText both default to true.

Limits and troubleshooting

  • The hook installation is empty in this source. It does not implement return-location announcements.
  • The README is an upstream starter template, not installation instructions for a finished mod.
  • A working build and in-game compatibility have not been established by preparing this documentation.
