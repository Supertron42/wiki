More Colorful UI

Give Skyrim’s activation text a color for each action. For example, make Steal red and Take green so the action is easier to recognize before you use it.

Get started

  1. Choose the plugin download for your exact Skyrim version and store edition. Use the matching SKSE and Address Library required by that download.
  2. Install the complete package with your mod manager, including its Data assets. Back up personal settings before replacing an older mod folder.
  3. Start Skyrim through SKSE. For these settings, restart Skyrim after saving changes unless the guide describes a separate reload control.

Settings

Edit Data/SKSE/Plugins/MoreColorfulUI.json. Each action name maps to a color such as #FF4444. Missing settings use the standard colors.

The gameplay plugin works on its own. You can edit its settings file with a text editor, or install Prisma UI Settings Menu and its requirements for an optional in-game editor. Press F10, choose the mod, save, and restart Skyrim. The menu definition shipped with a mod is separate from your personal settings file.

SettingWhat it changes
Action colorsChange actions such as Take, Steal, Open, Search, Talk and Read.
Prefix matchingThe longest matching action name wins. More specific action names can therefore take priority over shorter ones.
UpdatesChoose the installer’s no-settings option when keeping your preferences; keep a backup before replacing an old mod folder.

Limits and troubleshooting

  • Restart Skyrim after changing colors.
  • Action matching uses the label text. Translated or replaced action labels may need matching entries.
  • The color identifies a configured action label; it does not decide whether taking an item is allowed.
  • Other mods that replace activation text may need compatibility testing.
