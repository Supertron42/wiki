Current source notes

These are the current source notes. A source change needs a matching tested download before it is available to players. Use the overview for current setup and limits.

#NEW
- Added support for Prisma UI Settings Menu (PUISM)

#UPDATE
- Updated the default word colors, including a green Toggle action.
- Resetting colors in the settings menu now restores the updated palette.
- Choose your Skyrim version, including VR, from one download.
- Keep your settings or install the optional default settings file.

#FIXED
- When action names overlap, the longest matching name now gets the correct color.
- Default colors now work even if the settings menu definition is missing.
- The startup report now opens from its correct location in the settings menu.

Patch Notes

1.8.0 build candidate

  • One download: Choose Skyrim 1.5.97, 1.6.x, 1.7.104 or VR in the installer.
  • Optional settings: Keep your preferences or install the included standard JSON settings.
  • In-game settings: Change preferences with the optional Prisma UI Settings Menu, then restart Skyrim.
  • Standalone colors: Standard colors work without the settings menu definition.
  • Color matching: The longest matching action name wins consistently.
  • Reports: The startup HTML log appears in the current settings menu report location.
  • Startup compatibility. The startup declaration no longer depends on the removed SKSEAPI name, avoiding the reported compile error with CommonLibSSE-NG 7.5.1.

Compiled files still need testing in Skyrim before gameplay compatibility is confirmed.
