Action color settings

Match each displayed action prefix to its intended color.

Color entries

MoreColorfulUI.json maps action text to a color such as #FF4444. Standard entries include Take, Steal, Open, Search, Talk and Read.

Matching

The longest matching prefix wins. Matching follows the displayed text, so translated or replacement labels may need their own entries.

Save and restart

The optional menu edits the same JSON. Invalid colors use standard values where available while retaining the file; inspect the log if a color does not appear. Restart after changes.
