NPC Spawner

Spawn random eligible NPCs around your character on a timer, with controls for the interval, distance and maximum count. Spawning starts only when you use its shortcut.

Get started

  1. Choose the plugin download for your exact Skyrim version and store edition. Use the matching SKSE and Address Library required by that download.
  2. Install the complete package with your mod manager, including its Data assets. Back up personal settings before replacing an older mod folder.
  3. Start Skyrim through SKSE. For these settings, restart Skyrim after saving changes unless the guide describes a separate reload control.

Settings

Edit Data/SKSE/Plugins/NPCSpawner.json or use the optional settings menu. A recognized older INI is imported only when JSON is missing.

SettingWhat it changes
Start/stopThe default shortcut is Shift+F7. Shift+F8 reloads JSON settings.
Spawn controlsDefaults are a 2-second interval, a 30-NPC limit and a radius of 512 game units. Adjust them before starting a demanding test.
Eligible charactersUnkillable NPCs are skipped by default.
Stat boostsOff by default. Optional health, magicka and stamina boosts belong to this mod’s saved bookkeeping; turning them off and reloading removes its recorded boosts.

Limits and troubleshooting

  • Spawning and shortcut actions wait during paused menus.
  • Loading a save or starting a new game stops spawning. Already saved spawned characters are not automatically deleted.
  • Older saves without stat-boost bookkeeping cannot be corrected automatically; the mod does not guess which actor-value changes it owns.
  • Large spawn counts can stress the game. Use a separate test save and review the result before saving a normal playthrough.
