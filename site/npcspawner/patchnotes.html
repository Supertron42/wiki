Current source notes

These are the current source notes. A source change needs a matching tested download before it is available to players. Use the overview for current setup and limits.

#NEW
- Skip essential and protected NPCs by default, with an option to allow them in JSON or PUISM.
- Added support for Prisma UI Settings Menu (PUISM)

#UPDATE
- Set the time between spawns from 1 to 20 seconds.
- New settings spawn one NPC every 2 seconds and stop at 30 NPCs (configurable).
- Optional health, stamina, magicka and carry-weight bonuses stay off until you enable them.
- Choose your Skyrim version, including VR, from one download.

#FIXED
- Spawn and cleanup actions now wait for the game task queue instead of running inside keyboard input handling.
- Loading a save cancels queued spawn and shortcut actions from the previous game.
- New NPCs appear at their chosen position without first appearing at your feet.
- Disabled NPCs wait for their 3D to unload before being marked for deletion.
- Spawning and shortcut actions now wait while the game is paused.
- Loading another game clears old spawn and deletion requests.
- Turning player bonuses off removes the bonuses added by NPC Spawner, including after loading a save.
- Invalid spawn limits and distances now fall back to defaults instead of hanging the game.

Version history and release notes for NPC Spawner.

Version 1.0.0 - Initial Release

Features

  • NEW Random NPC spawning. Spawns a random NPC near the player on a configurable timer.
  • NEW Configurable spawn interval. Set how many seconds between each spawn (default: 2 seconds).
  • NEW Configurable NPC limit. Set the maximum number of spawned NPCs alive at once (default: 20). The oldest is removed when the limit is reached.
  • NEW Configurable spawn radius. Set how far from the player NPCs can appear (default: 512 game units).
  • NEW Smart NPC filtering. Skips unique characters, children, the player template, and deleted records. Only spawns generic NPCs.
  • NEW INI auto-generation. Creates a default INI file on first launch.
  • NEW Optional detailed logging. Log every spawn and removal with NPC name, position, and count.
  • NEW SE, AE, and VR support.
