Prisma UI Settings Menu

PUISM gives participating mods one optional in-game settings window. Choose a mod, change its settings, read its help and open its reports without searching through files.

Get started

  1. Install Prisma UI, PUISM, Media Keys Fix SKSE, and the matching SKSE and Address Library. VR also needs OpenComposite and the framework’s VR requirements.
  2. Load into Skyrim and press F10. Choose a supported mod in the list.
  3. Change a setting and wait for Saved. Use the question-mark help and Reset Tab when needed.
  4. Restart Skyrim to apply settings that affect startup processing. View Report opens the report supplied by that mod.

Settings

SettingWhat it changes
General and FeaturesControls supplied by the selected mod. Not every mod exposes the same options.
CompatibilityFor supported Dynamic mods, compare source records and make supported choices. Saving writes personal rules; it does not modify a live inventory.
RulesSearch personal and installed rules, inspect conflicts and filenames, or import/export supported personal choices. Installed packs remain separate.
Window sizeDrag the bottom-right handle. The same dimensions are retained between mods/tabs where storage is available. Keyboard resizing is available on the focused handle.
Name previewsSupported naming controls can show a formatting example before restart. A sample is not a change to the actual spell or item.

For mod authors

The public author kit supplies examples, a schema, menu metadata and optional integration headers. Authors keep their own defaults, validation and settings reader so the menu stays optional. The author’s provider decides which comparison fields can be edited; the hub does not turn every record into an unrestricted editor.

Limits and troubleshooting

  • PUISM needs participating mod definitions and matching menu/DLL assets. An older installed hub may not expose newly added controls.
  • The gameplay mods keep their own settings readers and work without PUISM or Prisma UI. Shared compatibility packs also do not require the menu.
  • No ESP is required for the menu.
  • A saved rule is eligible to affect a result; it is not a guarantee that every record passes the gameplay mod’s checks.
