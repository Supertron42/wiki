Current source notes

These are the current source notes. A source change needs a matching tested download before it is available to players. Use the overview for current setup and limits.

#NEW
- Review personal rules and installed compatibility packs in the Rules tab.
- Create mod groups and choose the game and DLC starting point by right-clicking plugins.
- See which rules affect a result and why that result was chosen.
- Edit supported amounts, levels, ranks and values directly from a result cell in the Compatibility tab.
- Right-click a plugin to skip its restored changes or leave its records as the last mod left them.
- Other menu mods can open and close PUISM directly without simulating a key press.
- Menu launchers can temporarily disable PUISMâ€™s opening shortcut while keeping Escape available.
- Browse plugins and compare changed records beside their final result across all five Dynamic mods.
- Left-click to select and right-click for choices, then save from the same Compatibility tab.
- Find records that need attention with clear status marks, explanations, and a Next issue button.
- Search installed plugins instead of typing their filenames into compatibility rules.
- Use the question mark for simple explanations and examples of each compatibility choice.
- Preview compatibility rules before saving them and search the rules you already added.
- Export compatibility rules and custom mod names as ZIPs that others can install with a mod manager.
- Choose an opening key with optional Ctrl, Shift or Alt to avoid other mod shortcuts.
- Mod authors can add searchable plugins, live previews, appearance priorities and guided compatibility rules to their own menus.
- The author kit includes example menus and code for reading shared settings without requiring PUISM.

#UPDATE
- Custom spell names now list mods that add spells without spell tomes.
- Spell and tome settings now have separate columns, larger live name previews, and clearer spacing.
- Save, undo or discard compatibility changes together across both tabs.
- PUISM stays at the top of the mod list, with a divider below it.
- Hide plugins with no changes by default, or uncheck the filter to show them.
- Record comparisons show every source plugin, including mods that forward unchanged contents.
- The window keeps its size when switching tabs or mods, with a corner handle to resize it.
- Settings appear in Features, General and Compatibility order where those tabs are used.
- Sliders are wider, and multiplier controls put 1x in the middle with a box for typing an exact value.
- Preview Tome and Spell Identifier names before restarting Skyrim.
- Tome and Spell Identifier's mod-name list only shows mods active in your current game, one row per mod, with an optional preview of that mod's names.
- Reports open inside the menu, and returning keeps your settings and scroll position.
- Reopening the menu remembers your last mod and tab.
- Review imported settings before accepting them without replacing unrelated preferences.
- Choose your Skyrim version, including VR, from one download.

#FIXED
- Show failed compatibility comparisons instead of labeling their records as unchanged.
- Fixed right-click menus not opening on plugins and table cells.
- Filtering the plugin list no longer triggers a settings save.
- Improved movement and mouse-control recovery when the menu closes or fails to open.
- Loading a save cancels old menu recovery so it cannot interfere with the newly loaded game.
- Save messages now show whether your settings were actually written.
- Export messages stay with the correct mod when you switch pages.
- Compatibility exports wait for your latest choices to finish saving.
- Switching pages during an import no longer lets the previous screen overwrite the imported settings.
