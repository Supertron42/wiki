Version 0.1.0 - Initial Source Alpha

Not yet built or tested in-game. These notes describe the current source; a ClibDT build and in-game validation are still required before a public release.

Features

  • NEW Perk check. Flags perks whose effect data does not match what the perk is supposed to do.
  • NEW Magic effect check. Flags magic effects whose settings do not match the type of effect they claim to be.
  • NEW AI package check. Flags AI packages that point at a broken or unrecognized target.
  • NEW Quest alias check. Flags quest aliases that point at something missing or out of range.
  • NEW Script check. Flags scripts attached to any record that failed to set up correctly, or whose properties point at something that no longer resolves.
  • NEW Findings report. A searchable report of everything found, written next to the SKSE log and to the optional in-game menu's report page.
  • NEW Per-check toggles. Each check can be turned off independently in the JSON settings file or the optional in-game menu.
