Compatibility

Understand how runtime weights interact with other mods.

Runtime values

Weights are applied at data load and reapplied from original values after loading a save. Other mods that alter weights later may affect what you see.

Skipped items

Non-playable and VendorNoSale items are skipped, but this does not identify every quest item. Test unusual equipment and mods with custom item types.

Optional menu

PUISM edits the same JSON and is not required for weight changes. This mod creates no required ESP.
