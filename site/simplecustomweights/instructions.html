Install and update

Keep personal weight preferences during an update.

Install

  1. Choose the plugin download for your exact Skyrim version and store edition. Use the matching SKSE and Address Library required by that download.
  2. Install the complete package with your mod manager, including its Data assets. Back up personal settings before replacing an older mod folder.
  3. Start Skyrim through SKSE. For these settings, restart Skyrim after saving changes unless the guide describes a separate reload control.

Keep preferences

Choose the installer’s no-settings option when retaining your existing JSON. Back it up before replacing the whole mod folder. Missing JSON is created at startup; supported INI values migrate once when JSON is absent.

Check the result

Read SimpleCustomWeights.log for changed/skipped totals and standard tool weights. A visible item can use a more specific category than expected.
