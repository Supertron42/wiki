Reload weights from a script

A small integration for authors who already use Papyrus.

Available function

The source registers SimpleCustomWeights.ReloadSimpleCustomWeights(). It calls the same reload engine used for settings, rather than repeatedly multiplying a previously changed weight.

When to use it

A script integration needs a matching Papyrus declaration and its own testing. Ordinary players can save their settings and restart Skyrim instead; no settings ESP is required.
