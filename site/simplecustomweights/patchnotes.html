Current source notes

These are the current source notes. A source change needs a matching tested download before it is available to players. Use the overview for current setup and limits.

#NEW
- Give notes and letters their own weight without changing books and journals.
- Adjust leather and hides separately from other miscellaneous items.
- Adjust ores and ingots separately from other miscellaneous items.
- Added support for Prisma UI Settings Menu (PUISM)
- Type an exact multiplier from 0.1x to 10x instead of dragging a slider.

#UPDATE
- Removed repeated slider explanations while keeping useful details about each weight category.
- All weight multiplier sliders run from 0.1x to 10x, with normal weight at 1x in the middle.
- Key, lockpick and gold weights have their own section below the multipliers.
- Set key and lockpick weights from 0.01 to 5, or keep their original weights.
- Set gold weight from 0 to 1.
- Set each arrow or bolt to an exact weight from 0 to 1 in steps of 0.01 in desktop Skyrim.
- Keep arrows and bolts weightless with 0, even when minimum item weight is enabled.
- Keep your old arrow multiplier until you choose an exact weight or restore original weights.
- Choose your Skyrim version, including VR, from one download.
- Keep your settings or install the optional default settings file.
- Import existing INI preferences into JSON without losing your settings.

#FIXED
- Pickaxes and woodcutting axes now use Tool weight.
- Misc weight no longer replaces more specific book or tool settings.
- Logs now explain skipped items and show the resulting pickaxe and woodcutting axe weights.
- Reloading settings no longer multiplies already changed item weights again.
- Invalid weight settings now use defaults instead of leaving items with broken weights.
