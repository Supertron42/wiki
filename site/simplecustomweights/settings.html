Weight settings

Set broad category choices, then review special cases.

Categories

Use category multipliers from 0.1× to 10×. Keep 1× for normal weight. Notes/letters/recipes, leather/hides, ores/ingots, tools and soul gems have their own choices. A specific category takes priority over Misc.

The upcoming source update also accepts 0 in the settings file to make a category weightless, including after loading settings again. The optional menu keeps its positive slider range. The rounding amount must stay above zero.

Arrows and bolts

Desktop ammo can keep original weight, use its previous multiplier, or use an exact value from 0 to 1. Exact zero is weightless and bypasses rounding/minimum weight. VR ammo is left unchanged.

Save and apply

Edit SimpleCustomWeights.json or save through the optional menu, then restart. An old INI is imported only while JSON is missing.
