Check unexpected weights

Start with the active settings file and category.

Find the active file

In MO2’s Data tab, find which mod or Overwrite entry supplies SimpleCustomWeights.json. Editing a hidden copy or an old INI will not change an existing active JSON.

Check the category

Use the text log for skipped-item reasons. A tool, soul gem, note or crafting material can use its specific category rather than Misc.

Check ammo mode

Keep original weight makes no ammo change. Exact ammo weight ignores multiplier rounding/minimums. VR ammo cannot use this editable field.

Report a reproducible case

Include your game version, current plugin build, relevant JSON settings, item/plugin identity and the matching log lines. Review the log before sharing it.
