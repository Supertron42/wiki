Stability Tester

Run a file-based scan for records identical to masters, deleted references, broken compression, oversized subrecords and invalid master references. It is a diagnostic prototype, despite the broader project name.

Experimental diagnostic source.

Get started

  1. Use a separately built and checked plugin in a test setup. The current template README is not a finished release guide.
  2. Press F7 by default to request a full scan. Wait for completion before starting another scan.
  3. Read the plugin’s SKSE log and investigate the reported plugin/record in an editor before changing it.

Settings

Settings prefer Data/MCM/Settings/StabilityTester.ini, then Data/SKSE/Plugins/StabilityTester.ini. The fallback INI is created if neither exists. You can change the scan hotkey, enable each scan category, and choose notification/logging options.

Limits and troubleshooting

  • This is not an automatic cleaning tool or a guarantee of a stable game. Duplicate records can be intentional.
  • The source runs its scan in a background thread; real-game behavior and long scans still need validation.
  • An MCM definition/script is present, but menu use needs its complete packaged requirements.
  • No PUISM integration is claimed for this project.
