TK Dodge NG

This project ports the TK Dodge RE plugin for additional Skyrim/VR builds. It supplies the plugin DLL, while the original mod still supplies animations and other required files.

Get started

  1. Install the original TK Dodge RE setup and its animation requirements using its author’s instructions.
  2. Install a checked TK Dodge NG DLL for your intended game build as the overwrite. Keep the original animation and other support files.
  3. Review TK Dodge RE.ini and test dodging on the intended runtime before relying on it in a playthrough.

Settings

SettingWhat it changes
DodgeHotkeyDefault scan code 56. Configure the intended key in TK Dodge RE.ini.
StepDodgeChoose a step instead of a roll.
DodgeStaminaDefault cost is 10.
EnableSprintKeyDodgeOptional sprint-tap behavior. The supplied INI identifies Classic Sprinting Redone as a requirement for this option.
Other choicesSneak dodging, attack canceling, in-place dodge and invincibility duration have separate settings.

Limits and troubleshooting

  • The source README targets Skyrim 1.6.1130+ and VR. That is a project target, not confirmation of every later game update.
  • The DLL alone is not a complete animation installation.
  • Other dodge, input and animation mods can require compatibility testing.
