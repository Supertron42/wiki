Tome and Spell Identifier

Choose labels that make spells and spell tomes easier to recognize. Show difficulty or magic school before or after the name, and give selected mods a short custom label for their tomes.

Get started

  1. Choose the plugin download for your exact Skyrim version and store edition. Use the matching SKSE and Address Library required by that download.
  2. Install the complete package with your mod manager, including its Data assets. Back up personal settings before replacing an older mod folder.
  3. Start Skyrim through SKSE. For these settings, restart Skyrim after saving changes unless the guide describes a separate reload control.

Settings

Edit Data/SKSE/Plugins/TomeAndSpellIdentifier.json, or use the optional menu’s Spell tomes, Spells and Custom names tabs.

SettingWhat it changes
LabelsChoose difficulty, magic school, position, parentheses and spacing.
Custom mod namesUse the plugin that originally added the tome, such as Apocalypse.esp. Custom source labels apply to tomes; spell labels use difficulty and school.
Live previewThe updated hub can show sample names as you edit. It illustrates formatting and does not change actual records until the game restarts.
TranslationsThe optional _Strings.txt file remains separate from JSON settings.

Limits and troubleshooting

  • A recognized INI is imported only when JSON is missing. Once JSON exists, editing the INI no longer changes the mod.
  • After a successful import, the message/log identifies the old INI. In MO2, use the Data tab to find which mod supplies it; imported JSON may be in Overwrite.
  • The mod does not delete the INI for you. Keep it if import fails, repair the problem, and restart.
  • A formatting preview is an example; actual names depend on the spell data and translations.
