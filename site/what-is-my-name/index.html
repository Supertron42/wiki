What Is My Name

The prototype suggests a name from a built-in list for the character’s race and sex when the character-creation menu opens.

Unverified source prototype.

Get started

This is source work rather than a finished player download. Its intended trigger is opening the race/sex menu while the current name is empty or Prisoner. A name you already chose is left alone.

Settings

There is no settings file or reroll shortcut in the current source. Ten base-game races have built-in name lists; unknown races use a fallback list.

Limits and troubleshooting

  • Changing race or sex after the menu opens is not a documented live reroll workflow.
  • The source’s plugin loading entry point still needs build/runtime verification. Do not assume the prototype currently loads correctly.
  • Names are suggestions from fixed lists; they are not generated biographies or custom-race naming rules.
